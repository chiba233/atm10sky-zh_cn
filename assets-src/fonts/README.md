# 艺术字用的中文字体

`scripts/gen_quest_banners.py` 会**优先**读这个目录里的字体；找不到才退回系统自带的那几款。

**字体二进制不入 git**（十几 MB，而生成好的 PNG 已经在仓库里，玩家装包和 CI 都用不到）。
要重跑生成脚本，先执行：

```bash
./scripts/fetch_fonts.sh
```

## 点阵中文（脚本自动下载的那两个）

| 文件 | 用途 |
|---|---|
| `pixel-10.ttf` / `pixel-12.ttf` | 画 MC 那种硬边方块字的标题（通用机械 / 铁路工艺 / 基础物流 等 90 多张） |
| `pixel-OFL.txt`、`pixel-LICENSES/` | 上面两个的授权 |

取的是 [缝合像素字体 Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)
的 `zh_hans` 比例宽度版，**OFL-1.1**。它由方舟像素字体 + Cubic 11 + Galmuri 拼合而成，
专门补全汉字覆盖——方舟本体的 zh_cn 12px 缺「旋热然聚嗡蟒骏」这类常用字，
缺字会渲染成 .notdef 豆腐块（「斯库拉」「植被」都这么翻过车）。

**为什么要两档**：放大倍率只能取整数（取不整就不是硬边像素了），字框越高台阶越粗。
只用 12px 时有十几张图会比理论尺寸小一档，备一档 10px 兜着。生成脚本逐张挑，
且只有在小字框**没把笔画糊到一起**（数封闭内白判定）时才允许降档。
8px 那档试过又撤了——字框只剩 7px，「斯」「械」「塔」的笔画会粘死。

## 其余风格（可选，放了就用）

文件名（不含扩展名）就是脚本里的字体名，`.ttf` / `.otf` / `.ttc` 都行：

| 文件名 | 用途 | 建议字体 | 许可 |
|---|---|---|---|
| `serif.ttf` | 粗衬线标题（天境 / 蜜蜂领域 / 自然灵气 / 遗物） | 思源宋体 Heavy、霞鹜文楷、汇文明朝体 | OFL |
| `bold.ttf` | 粗黑标题（机械动力 / 禁忌与奥秘） | 思源黑体 Heavy、得意黑 Smiley Sans | OFL |
| `thin.ttf` | 细体标题（更深更暗 / 动态联合） | 思源黑体 Light | OFL |
| `deco.ttf` | 装饰体（灾变 / 神秘学 这类怪奇风） | 站酷系列、字魂免费商用系列 | 看各自授权 |

没放也能跑：这几档会退回系统自带的冬青黑 W3/W6 与宋体 SC Black，只是风格没那么贴原图。

## 注意

- 只放**允许再分发**的字体（OFL / 明确免费商用）。本仓库是 GPL-3.0 公开发布的，
  字形会以 PNG 形式随资源包分发给玩家，授权不清楚的不要放。
- 放好后直接重跑 `python3 scripts/gen_quest_banners.py` 即可，不用改代码。
