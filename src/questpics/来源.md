# 这几张图是哪来的

ATM10 Sky 2.0.4 的任务书章节引用了这七张配图，而整合包自己的官方文件里没有它们。
缺失纹理在游戏里就是那片品红黑格，会把「建筑技巧」整章和通用机械章的排版打花——
不装本包同样如此，成因在上游，但玩家看到的是「我装了这个包，任务书是花的」。

七张全部取自 **All the Mods 10** 的官方文件（同一套 `atm:` 命名空间、同一个作者组
AllTheMods），逐字节原样收录，未作改动：

| 文件 | 内容 | 要不要汉化 |
|---|---|---|
| `building_tips/building_frame.png` | 金色相框，纯图案 | 无文字，不需要 |
| `building_tips/building_mindful.png` | 建筑截图 | 无文字，不需要 |
| `building_tips/building_title_beelumpi.png` | 创作者名字招牌 Beelumpi | 人名，保持原样 |
| `building_tips/building_title_climowitz.png` | 创作者名字招牌 Climowitz | 人名，保持原样 |
| `building_tips/building_title_mindful.png` | 创作者名字招牌 Mindful Minecraft | 频道名，保持原样 |
| `building_tips/building_title_unka.png` | 创作者名字招牌 Unka | 人名，保持原样 |
| `mek/mek_wind.png` | 风力发电机渲染图 | 无文字，不需要 |

**只收录「本包引用了、本包官方文件里又没有」的那几张。** 上游哪一版把图补回来了，
`gen_missing_questpics.py --prune` 会在组该版出货树时把我们这份剔掉，谁也不覆盖谁。
