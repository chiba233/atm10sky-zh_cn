# 末影驱动器！

末影驱动器专注于一种不同的物品存储方式。这些驱动器会根据为每个驱动器设置的频率进行连接。所有具有相同频率和隐私设置的驱动器都会共享相同内容，无论是谁制作的都一样。无论是在你的 AE2 系统中、另一个维度中，还是其他玩家的系统中，其内容都会进行全局同步。
