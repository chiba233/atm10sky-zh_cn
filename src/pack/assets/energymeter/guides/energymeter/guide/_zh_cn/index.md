# 电能表

欢迎查阅**电能表**模组的介绍页！

<br clear="all" />

![](assets/preview.png)

<FloatingImage src="assets/logo.png" align="right"/>

电能表是一款小型内容模组，它新增了一种名为<ItemLink id="meter" components="rarity=epic"/>的方块，用来测量能量的流动速率。
该方块的运作方式类似于一段电缆：流入的能量请求会被直接转发到输出侧。所有这些请求所携带的数值都会被记录下来，并按照可自定义的时间间隔用于计算流速。

除了功能齐全的用户界面之外，该方块正面还带有一块数字显示屏，可以随时查看当前的流速数值。显示屏的朝向可以调整到任意方向，包括朝上或朝下。由于电能表的正面被显示屏占用，因此只有其余五个面可以被设为输入或输出。

若想回顾此前各个时间间隔的流速，电能表的用户界面中还内置了图表视图，可以展示最近10个时间间隔的测量数据，并且支持暂停查看。此外，界面还提供了大量额外的配置选项：除了可选择不同的测量方式外，测量间隔和计算方式也都可以自由调整。<br/>
更多细节请参阅[界面](interface.md)页面。
