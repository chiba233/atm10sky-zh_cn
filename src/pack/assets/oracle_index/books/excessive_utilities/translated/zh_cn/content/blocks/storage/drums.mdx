**圆桶**可以存储大量的单一流体，被破坏时保留里面的内容。

默认容量如下：

| 圆桶 | 容量（mB） |
| ---- | ------------- |
| 石头圆桶 | 16,000 |
| 铁圆桶 | 256,000 |
| 强化大型圆桶 | 4,096,000 |
| 恶魔巨型圆桶 | 65,536,000 |
| 基岩圆桶 | 1,048,576,000 |
| 创造模式圆桶 | MAX_INT |

## 配置

每一级的容量都可以配置。
