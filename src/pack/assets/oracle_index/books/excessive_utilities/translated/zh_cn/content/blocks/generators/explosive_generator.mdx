**爆炸发电机**燃烧某些易爆物品来产生 FE。

## 配置

爆炸发电机使用 `excessive_utilities:single_item_fuel` 配方类型。可以参照这个例子：

```json
{
  "type": "excessive_utilities:single_item_fuel",
  "duration": 3200,
  "fe_per_tick": 160,
  "generator_type": "explosive",
  "ingredient": {
    "item": "minecraft:tnt"
  }
}
```
