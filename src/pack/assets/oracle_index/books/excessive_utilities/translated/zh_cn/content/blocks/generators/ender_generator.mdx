**末影发电机**燃烧某些末地主题的物品来产生 FE。

## 配置

末影发电机使用 `excessive_utilities:single_item_fuel` 配方类型。可以参照这个例子：

```json
{
  "type": "excessive_utilities:single_item_fuel",
  "duration": 1600,
  "fe_per_tick": 40,
  "generator_type": "ender",
  "ingredient": {
    "tag": "c:ender_pearls"
  }
}
```
