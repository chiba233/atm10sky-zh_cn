- 彩色煤炭块
- 彩色圆石
- 彩色荧石
- 彩色青金石块
- 彩色黑曜石
- 彩色木板
- 彩色石英块
- 彩色红石块
- 彩色红石灯
- 彩色灵魂沙
- 彩色石砖
- 彩色石头
- 纯色光屏

这些方块的行为与各自的基础方块相同。为了不给每种颜色单开一页，它们合写在这里。
