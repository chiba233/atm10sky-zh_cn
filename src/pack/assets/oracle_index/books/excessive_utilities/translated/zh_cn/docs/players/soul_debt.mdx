# 灵魂债务

灵魂债务记录有多少枚[灵魂碎片](@excessive_utilities:soul_fragment)与你的玩家绑定。默认值为 0。它可以为正，也可以为负：

- **灵魂剩余**表示你吸收的灵魂碎片多于移除的。
- **灵魂债务**表示你移除的灵魂碎片多于吸收的。

每一点都会按服务端配置项**每灵魂碎片生命值**改变你的最大生命值。默认为 **2 点生命值**，也就是一颗心。

## 灵魂碎片

灵魂碎片是实体的稀有掉落物。基础掉落概率约为 **4300 万分之一**。用[鬼哭](@excessive_utilities:kikoku)击杀时，会额外进行一次概率约为 **430 万分之一**的判定。

使用灵魂碎片会吸收它，让你的灵魂剩余加 1。按默认配置，这会让你的最大生命值增加一颗心。

灵魂碎片的提示框会显示你当前的灵魂债务或灵魂剩余，以及这套机制当前给出的最大生命值修正。

## 移除碎片

用[以太之剑](@excessive_utilities:etheric_sword)可以从自己身上移除一枚灵魂碎片。成功时，你会得到一个灵魂碎片物品，记录的总数减 1。

如果移除会让你的最大生命值降到 0 或更低，以太之剑不会移除碎片。

## 死亡时的处理

服务端配置决定你死亡时如何处理灵魂债务和灵魂剩余：

| 设置 | 行为 |
| --- | --- |
| `KEEP` | 保留全部灵魂债务和灵魂剩余。这是默认值。 |
| `RESET` | 死亡时重置为 0。 |
| `REMOVE_NEGATIVE` | 保留灵魂剩余，但清除灵魂债务。 |
