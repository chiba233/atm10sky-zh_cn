# 网格能量

网格能量（**GP**）是按玩家计算的能量预算。GP 不经过线缆或电池流动。方块和物品归属于某个玩家，产能设备为该玩家的网格增加容量，耗能设备在运行时占用其中一部分容量。

如果 GP 用量高于 GP 容量，你的网格就会过载。过载时，耗 GP 的设备停止工作，直到用量下降或你增加产能。

## 查看你的网格

当前 GP 显示为：

```
used / capacity GP
```

手持能显示 GP 的物品（例如**能量管理器**），或看向带有 GP 显示标签的方块时，屏幕上会出现 HUD。如果显示为红色，说明你的网格已过载。

用**能量管理器**可以在聊天栏列出当前的产能设备和耗能设备。它会列出正在计入你网格的方块和物品，能取到坐标时还会附上坐标。

## 共享网格能量

玩家可以组成共享网格，合并所有成员的 GP 容量和用量。方块和物品仍归放置或使用它们的玩家所有。加入或离开共享网格，只改变哪些总量被合并。

用 `/excessive-utilities grid invite <player>` 邀请一名在线玩家。单人玩家发出的邀请第一次被接受时，该玩家成为网格所有者。只有所有者能邀请或移除成员。

| 命令 | 效果 |
| --- | --- |
| `/excessive-utilities grid invite <player>` | 邀请一名在线玩家加入你的网格。 |
| `/excessive-utilities grid accept` | 接受当前的网格邀请。 |
| `/excessive-utilities grid decline` | 拒绝当前的网格邀请。 |
| `/excessive-utilities grid leave` | 离开当前的共享网格。 |
| `/excessive-utilities grid kick <player>` | 移除一名成员。该成员离线时也能使用。 |
| `/excessive-utilities grid members` | 列出当前与你共享 GP 的所有人。 |

所有者离线时，任何成员都可以离开。所有者离开时，由另一名成员接任所有者。只剩一名玩家时，共享组被移除，这名玩家回到单人网格。离开或被移除，都不会改变你放置的任何东西的归属。

网格组随世界保存。邀请是临时的，服务器重启时清空。

| 产能设备 | 默认 GP | 说明 |
| --- | ---: | --- |
| [手动发电机](@excessive_utilities:manual_mill) | 每名玩家 15 | 有玩家摇动时产能。 |
| [太阳能面板](@excessive_utilities:solar_panel) | 1 | 需要能看到天空，且为白天。下雨时产量降低 5%。 |
| [月光面板](@excessive_utilities:lunar_panel) | 1 | 需要能看到天空，且为夜晚。下雨时产量降低 5%。 |
| [熔岩发电机](@excessive_utilities:lava_mill) | 2 | 需要水平相邻处有熔岩。 |
| [火力发电机](@excessive_utilities:fire_mill) | 4 | 需要正下方有火。 |
| [水力发电机](@excessive_utilities:water_mill) | 每面 4 | 计算水平相邻的流动水，不计水源方块。 |
| [风力发电机](@excessive_utilities:wind_mill) | 不定 | 需要南北两面畅通。产量随时间变化，下雨或雷暴时更高。 |
| [龙蛋发电机](@excessive_utilities:dragon_egg_mill) | 500 | 需要顶部放一枚龙蛋。 |

## 耗能设备

耗 GP 的设备只在有活要干时占用能量。以下是常见的默认消耗：

| 耗能设备 | 默认 GP | 何时消耗 |
| --- | ---: | --- |
| 鸡翅膀指环 | 1 | 按住跳跃键减缓下落时。 |
| 飞鱿指环 | 16 | 按住跳跃键向上推进时。 |
| 天使指环 | 64 | 飞行时。创造模式玩家不付这笔消耗。 |
| 红煤 | 4 | 熔炉里红煤的加速燃烧生效时。 |
| 无线FE传输器 | 每个连接 1 | 上一刻收到 FE 的每个目标各算一次。 |
| 共振仪 | 配方消耗加上速度升级的消耗 | 有有效配方且输出有空位时。 |

其他由 GP 驱动的机器和传输节点，运行时也会占用 GP。要在游戏里查看确切的实时消耗，最方便的是用能量管理器。

## 过载的影响

过载检测比较你单人网格或共享网格的总用量与总容量。

- **天使指环**过载时失去创造模式飞行效果。
- **共振仪**过载时暂停进度。
- 会检测过载的 GP 方块会停止工作，直到 GP 重新够用。

增加产能、等临时耗能设备结束，或关闭、移除耗能设备，都能解除过载。

## 实用搭建

先用**手动发电机**或靠环境发电的发电机，攒出一点容量余量。对于早期的飞行物品，记住鸡翅膀指环和飞鱿指环只在主动使用时消耗 GP，而天使指环只要你在飞行就会消耗 GP。

对于机器，在标出的配方消耗或机器消耗之上留一些富余容量。速度升级能提高处理量，但也会增加 GP 消耗。所以不装升级时运转正常的机器，装上升级后可能过载。
