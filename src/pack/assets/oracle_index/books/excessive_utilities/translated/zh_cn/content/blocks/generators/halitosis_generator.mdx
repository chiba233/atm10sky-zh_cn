**龙息发电机**燃烧龙息来产生 FE。

## 配置

龙息发电机使用 `excessive_utilities:single_item_fuel` 配方类型。可以参照这个例子：

```json
{
  "type": "excessive_utilities:single_item_fuel",
  "duration": 12000,
  "fe_per_tick": 40,
  "generator_type": "halitosis",
  "ingredient": {
    "item": "minecraft:dragon_breath"
  }
}
```
