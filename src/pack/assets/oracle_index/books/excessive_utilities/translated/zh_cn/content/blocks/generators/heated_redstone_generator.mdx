**高热红石发电机**同时燃烧熔岩和红石来产生 FE。

## 配置

高热红石发电机使用 `excessive_utilities:magmatic_fuel` 配方类型。可以参照这个例子：

```json
{
{
  "type": "excessive_utilities:magmatic_fuel",
  "duration": 1,
  "fe_per_tick": 100,
  "ingredient": {
    "amount": 1,
    "tag": "c:lava"
  }
}
```
