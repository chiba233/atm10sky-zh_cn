**霜冻发电机**燃烧某些冰冷的物品来产生 FE。

## 配置

霜冻发电机使用 `excessive_utilities:single_item_fuel` 配方类型。可以参照这个例子：

```json
{
  "type": "excessive_utilities:single_item_fuel",
  "duration": 40,
  "fe_per_tick": 40,
  "generator_type": "frosty",
  "ingredient": {
    "item": "minecraft:ice"
  }
}
```
